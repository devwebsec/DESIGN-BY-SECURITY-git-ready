# Security Policy

## Scope

This repository contains security-architecture methodology, prompts, integration contracts, tests and packaging tooling. It is not a production service and does not claim to provide complete protection by itself.

## Reporting a Vulnerability

Please report suspected security issues privately to the repository owner through the contact mechanism configured for this repository (for example, GitHub private vulnerability reporting, when enabled).

Do not publish exploit details, credentials, tokens or other sensitive information in a public issue.

A useful report includes the affected file/path, security impact, reproduction context, and a minimal proof sufficient to validate the finding.

## Security Maintenance

Changes to prompts, contracts, integration adapters, packaging scripts or test gates should be reviewed as security-sensitive changes. CI must pass before merge to `main`.

This project does not promise a fixed response SLA unless one is explicitly published by the repository maintainers.
